# 天火计划（Project Skyfire）

根据 [游戏规格](GAME_SPEC_Project_Skyfire.md) 实现的竖屏飞机射击游戏 MVP。包含 5 个关卡、5 种可升级武器、10 种道具、三阶段 Boss、经验升级时自动随机强化、暂停与结算、浏览器本地存档，以及开发环境压力测试工具。

## 环境

- Node.js 22.12+（或兼容 Vite 8 的更新版本）
- pnpm 11

## 启动

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。逻辑画面为 540 × 960，窗口通过 Phaser FIT 模式适配。

## 操作

- WASD、方向键或按住鼠标 / 手指拖动飞机；武器自动攻击。
- 右上角按钮或 Esc 暂停。经验升级自动随机选择强化，不中断战斗。
- 主菜单的“开始游戏”始终从第 1 关开始；通关后可继续下一关，进度保存在浏览器本地。
- 点击喇叭切换声音开启或静音；开启时会播放试听音。射击、命中、爆炸、拾取和升级均有音效。
- 开发环境按 F2 打开调试面板。F3 显示碰撞框，K 清敌、B 生成 Boss、U 升级、H 治疗、G 无敌、P 压力测试、N 结束本关、I 预览全部道具。生产构建中没有这些快捷键。

## 验证

```bash
pnpm test
pnpm build
pnpm lint
pnpm format:check
```

`pnpm preview` 可预览构建产物。音效使用浏览器 Web Audio 实时合成；游戏目前没有背景音乐素材。
