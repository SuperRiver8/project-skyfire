# 天火计划（Project Skyfire）

根据 [游戏规格](GAME_SPEC_Project_Skyfire.md) 实现的竖屏飞机射击游戏 MVP。当前提供连续的 5 关、5 种可升级武器、12 种道具、每关 Boss、自动随机强化、暂停与结算、浏览器本地存档，以及开发环境调试工具。下方规则以当前代码为准。

## 环境

- Node.js 22.12+（或兼容 Vite 8 的更新版本）
- pnpm 11

## 启动

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。逻辑画面为 540 × 960，窗口通过 Phaser FIT 模式适配。

项目版本号统一维护在 `package.json` 的 `version` 字段，首页会自动显示对应的 `v` 前缀版本号。

## 游戏流程

1. 主菜单开始游戏，从第 1 关开始。战机自动射击，玩家负责移动、躲避和拾取。
2. 每关按时间和编队配置刷出敌机，同类敌机会在多种外观款式间轮换且体型略有差异。击落敌机会留下经验球，靠近后自动吸附；敌机不会直接掉道具。
3. 场上按随机间隔从顶部掉落随机道具，接触后立即生效。不同道具具有不同抽取权重。
4. 到达关卡指定时间且该关编队全部生成后，清理场上敌机和敌弹，出现 Boss 预警，约 1.8 秒后开战。**每一关都必须击败对应关卡的专属 Boss 才算通关**。
5. 第 1～4 关击败 Boss 后自动进入下一关，中央显示 2 秒“已进入第 N 关”。生命、护盾、等级、经验、武器与永久生效的本局强化会延续到下一关。第 5 关获胜后显示结算；生命归零且无法复活时显示失败结算。

| 关卡 | 名称     | 普通敌机阶段 | Boss          | Boss 生命倍率 | 通关金币 |
| ---- | -------- | ------------ | ------------- | ------------: | -------: |
| 1    | 初次升空 | 75 秒        | 机械雄鹰      |          0.35 |       50 |
| 2    | 交叉火力 | 90 秒        | 钢铁飞龙      |          0.50 |       70 |
| 3    | 红色警戒 | 95 秒        | 双头蛇        |          1.05 |       90 |
| 4    | 最后防线 | 110 秒       | 铁壁堡垒      |          1.30 |      120 |
| 5    | 天空帝皇 | 28 秒        | 天空帝皇      |          1.60 |      180 |

**每一关的 Boss 造型与技能机制完全不同：**

| Boss     | 造型                                   | 专属技能组合                             | 定位                     |
| -------- | -------------------------------------- | ---------------------------------------- | ------------------------ |
| 机械雄鹰 | 蓝灰钛合金巨鹰，金属羽片、红色电子眼、红色过载核心 | 猎鹰扇射 / 双翼追踪导弹 / 翼刃激光扫射 / 红线俯冲 | 高速俯冲型·新手教学 |
| 钢铁飞龙 | 赤黑机械飞龙，双角龙首、双层龙翼、熔岩熔核、节段钢尾 | 龙炎吐息 / 熔核火雨 / 烈焰龙翼斩 / 钢尾横扫 | 大范围火力压制型 |
| 双头蛇   | 一体双头，毒能绿首 + 电浆紫首，节状装甲与能量翼膜 | 毒首扩散 / 雷首锁链 / 双首夹击 / 双首交替追击 / 灾厄共鸣 | 双核心双机制型 |
| 铁壁堡垒 | 悬浮战争要塞，多层装甲、铆钉、炮仓与三联引擎 | 重炮齐射 / 导弹仓弹幕 / 护盾矩阵 / 三通道封锁 / 三引擎冲锋 | 防御压制型·阵地型 |

所有 Boss 均为三阶段：前两关生命降至约 70～72% 和 35～36%、后三关降至约 78～80% 和 45～46% 时进入下一阶段，换色并强化技能（技能间隔随阶段缩短，部分技能在 2、3 阶段解锁）。技能均为独立实现：龙炎吐息持续喷吐火柱，双头蛇会交替追击，铁壁堡垒会预警封锁三条通道，天空帝皇会蓄力后连续追猎。Boss 左右移动时带有 Roll 倾斜、阴影偏移、尾焰变化与机翼透视变化；均有多层贴图结构、独立发光核心、出场滑落、阶段切换震屏变色与分段爆炸死亡演出。

## 战机成长与战斗

- 战机初始生命 100。左上角生命和经验以进度条显示，等级显示为 `LV 1`、`LV 2` 等。受击后有 700 毫秒短暂无敌。生命为 0 时，若持有凤凰核心则先复活一次，否则游戏结束。
- 敌机死亡产生经验球；经验需求公式为 `floor(40 × 当前等级^1.35)`。升级时自动从三个随机候选中选取一个强化，战斗不中断。等级达到 3 和 6 时战机外观升级。
- 可用武器：机枪、散射枪、激光、导弹、闪电链。机枪为初始武器，其余通过升级获得，散射枪也可由永久道具解锁和升级；可同时装备全部武器，各武器最多升到 5 级。它们均自动开火，升级会改变火力效果。
- 攻击核心每个提高约 15% 攻击倍率，最多 5 个；急速核心每个提高约 12% 射速倍率，最多 5 个。暴击核心每个增加 5 个百分点暴击概率。初始暴击概率为 5%，暴击伤害倍率为 1.5。

| 武器   | 战斗方式                               | 升级方向                                       |
| ------ | -------------------------------------- | ---------------------------------------------- |
| 机枪   | 向前连续射击。                         | 双管、射速、三线射击，最高级可穿透。           |
| 散射枪 | 向前发射扇形弹幕。                     | 增加弹数与伤害。                               |
| 激光   | 间歇发射直线光束，可命中路径上的敌机。 | 加宽光束、提高伤害、双光束。                   |
| 导弹   | 自动追踪目标并造成范围伤害。           | 增加导弹数量与爆炸范围，最高级有追加范围伤害。 |
| 闪电链 | 自动攻击目标并向附近敌机连锁。         | 增加连锁数量与伤害。                           |

普通敌机共有六类 AI，外观款式却有 14 种贴图，同类敌机在编队中会轮换不同款式：

| 机型 | AI 行为                                   | 外观款式（编队内轮换）           | 体型 |
| ---- | ---------------------------------------- | ------------------------------- | ---: |
| 侦察机 | 直线下飞                                   | 基础型 / 王牌后掠翼 / 长针箭形     | 小   |
| 之字机 | 左右摆动                                   | 折线翼 / 宽幅蝠翼 / 黄蜂窄翼带尾针 | 中小 |
| 射手   | 发射瞄准弹                                 | 基础型 / 重型炮塔 / 中央长炮狙击型 | 中   |
| 突击机 | 短暂预警后冲向玩家                         | 前铲型                           | 中大 |
| 自爆机 | 贴近后引爆                                 | 核心型 / 超载双重光晕型           | 小   |
| 重坦克 | 血厚、发射多发子弹                         | 基础重甲 / 魔像级加宽装甲         | 大   |

每架敌机在基础体型上还有 ±14% 的确定性随机浮动，同一编队里大小参差不齐（碰撞框固定不变，不影响难度）。所有普通敌机均可射击，开局侦察机的射击间隔较长且子弹较慢；每波敌机数量为原配置的两倍，清屏后的长间隔会补充少量敌机。敌机接触、敌弹和 Boss 攻击都可能造成伤害；击落敌机增加得分并产生经验球。

## 视觉风格

全部战斗单位采用 Canvas 渐变绘制的伪 3D 风格贴图：

- **战机**：机身横向渐变营造圆柱曲面感、机翼顶光渐变、球面座舱反光、外发光轮廓、发光翼尖灯。玩家战机随等级升级三种形态（青蓝 → 亮青 → 金色凤凰）；敌机与 Boss 造型各异。
- **喷射火焰**：三层锥形渐变火焰（外焰/内焰/焰心）叠加呼吸脉动，玩家为青蓝焰，敌机/Boss 为橙焰，狂暴/预警时变色。
- **子弹**：玩家弹为亮头深尾渐变弹体 + 消散拖尾光；敌弹为球面渐变红球 + 高光点；追踪导弹为金属圆柱弹体 + 发光红头 + 尾翼 + 双层尾焰与飞行拖尾。
- **道具**：球面渐变球体按道具着色，外带旋转双环光环与脉动；经验球为青绿菱形发光体（大经验为金色），带呼吸脉动与旋转。
- **爆炸**：径向渐变火球（白心→橙边）+ 快速扩散的冲击环；导弹与 Boss 追踪弹拖尾用双层线迹模拟光晕。

## 随机道具

开局约 4 秒出现首个道具，此后每隔约 5～8 秒在随机横向位置生成一个；道具从屏幕顶部落下，靠近战机会吸附。种类依配置权重随机抽取。开发调试道具预览不影响正常掉落规则。

| 道具     | 效果                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 攻击核心 | 本局攻击倍率提高，最多叠加 5 个。                                                                                                                                        |
| 急速核心 | 本局射速倍率提高，最多叠加 5 个。                                                                                                                                        |
| 暴击核心 | 本局暴击概率提高 5 个百分点，最多不超过 100%。                                                                                                                           |
| 能量护盾 | 战机周围出现呼吸光圈，按层数变换颜色；最多保留 5 层，每次碰机或受到攻击消耗 1 层，替代生命伤害。                                                                         |
| 电击能量 | 战机机身持续环绕闪电，靠近侦察机或之字机时自动锁定并持续电击，也可攻击范围内的 Boss。每拾取一次提高伤害与范围，最多 5 级。闪电链武器也会激活机身闪电环绕效果。 |
| 散射枪 | 永久解锁或升级散射枪；道具与升级选择共享武器等级，最多 5 级，满级后不再掉落。 |
| 追踪导弹系统 | 独立于主武器槽，自动从两侧交替发射追踪导弹；掉落权重提高一倍。每级每秒增加 2 枚，最多 5 级、每秒 10 枚。满级后再拾取可提高导弹伤害，最多 3 次。 |
| 维修装置 | 恢复 30 生命；生命已满时增加 1 层护盾，仍受 5 层上限约束。                                                                                                               |
| 吸附磁铁 | 立即收集场上全部经验球。                                                                                                                                                 |
| 狂暴模式 | 10 秒内提高攻击与射速倍率。                                                                                                                                              |
| 时间冻结 | 5 秒内显著减慢敌机与敌弹。                                                                                                                                               |
| 凤凰核心 | 持有期间可在致命受击后复活一次，复活时清弹并清理附近敌机。                                                                                                               |

## 暂停、结算与存档

- 右上角暂停按钮或 `Esc` 打开暂停页面，可继续、重新开始当前关或返回主菜单；右上角喇叭按钮控制声音。
- 前四关击败 Boss 后自动记录关卡金币与统计并进入下一关；第五关和失败时显示结算。重新挑战会从当前关以初始配置开始。
- 浏览器 `localStorage` 保存最高解锁关卡、累计金币、战斗统计和声音等设置；每次在主菜单点击“开始游戏”仍从第 1 关开局。

## 操作

- WASD、方向键或按住鼠标 / 手指拖动飞机；武器自动攻击。
- 右上角按钮或 Esc 暂停。经验升级自动随机选择强化，不中断战斗。
- 点击喇叭切换声音开启或静音；开启时会播放试听音。射击、命中、爆炸、拾取和升级均有音效。
- 开发环境按 F2 打开调试面板。F3 显示碰撞框，K 清敌、B 生成 Boss、U 升级、H 治疗、G 无敌、P 压力测试、N 强制结束本关、I 预览全部道具。生产构建中没有这些快捷键。

## 验证

```bash
pnpm test
pnpm build
pnpm lint
pnpm format:check
```

`pnpm preview` 可预览构建产物。音效使用浏览器 Web Audio 实时合成；游戏目前没有背景音乐素材。

## 部署

运行 `pnpm build` 后，将 `dist` 目录中的 `index.html` 和 `assets` 目录一起上传到服务器的 `/skyfire/` 目录，访问 `https://域名/skyfire/`。构建产物使用相对资源路径，`index.html` 中的 JS 和 CSS 会从 `/skyfire/assets/` 加载。

如果服务器为单页应用配置了 HTML 回退规则，需让实际存在的 `/skyfire/assets/` 文件优先按静态文件返回；不要把缺失的 JS/CSS 请求回退成 `index.html`。更新部署时应同步上传新生成的 `index.html` 与其引用的 `assets` 文件。
